# Python Calculator

My first Python project. This is a simple calculator built using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Allows the user to quit the calculator

## How to Run

1. Make sure Python is installed.
2. Download `calculator.py`.
3. Open it with Python or run it from the terminal.
4. Follow the instructions on the screen.
